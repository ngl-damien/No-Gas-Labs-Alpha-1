# The Common Ground

The browser game is an authored, local playable projection of No_Gas_Labs. It does not replace the canonical institutional kernel or assert external AI execution, visitors, demand, truth, revenue or authority.

`game/index.html` loads the parchment and ink world. **Play your world** opens the device’s private save. **Enter the shared world** obtains the server’s current session, initially Witness. **Caveman Launchpad** opens a private world when entered from the doorway, creates an actual comic, Unicode loom and source observatory through the ordinary draft/publication actions if that world is empty, runs the actual local rehearsal and opens a downloadable exhibition. In an existing shared world only an authenticated Founder may run the launch action. The rehearsal publishes no message or public deployment. Existing worlds do not receive duplicate starter exhibits.

## Walking and access

The canvas owns one keyboard controller: WASD/arrows move; E or Space interacts. Tap the ground to request a route, use the touch directional pad, or open **Places** for named destinations and creation links. The 1600×1000 map has real river collision, two bridges and building footprints. Routing uses walkable grid points and retains its route when nongeometric state updates arrive. The camera follows the orange-beanie player; reduced motion removes the walking bob and camera interpolation. Presence displays actual server presence entries only, filtering the current session’s `presenceId`. Private play separately stores the last bounded map coordinates on this device and restores them on return; shared play continues to use session presence and does not treat the private position record as shared identity or authority.

Four discoveries provide explicitly authored guides: Relay (portable requests), River (receipt versus claim), Long View (retained repair), and Unfinished (small working artifacts). Discovery persists per actor without XP. Modal panels support Escape, focus restoration and a focus loop; editable controls do not move the player. Responsive layouts cover 320, 390 and 412px phones and desktop. There is no external font, rendering dependency or model provider.

Guild Hall also provides four bounded collaborator contracts (Hostile Archivist, Adversary, Synthesis Clerk and Polymath Tutor). The player copies a source-bound hand-off packet to an external provider and pastes the returned text back; no provider is called by the game. An explicit archive action asks the world model (and, in shared play, the server) to regenerate the exact actor-visible packet, reject stale or altered packets, structurally validate the response, and retain the exact packet and response with actor attribution and SHA-256 byte receipts. Both structurally valid and rejected responses remain in world history. The Guild Hall quest counts preservation only: structural validation is not truth, evidence, execution, approval, mastery, XP or authority. The Evidence Archive exposes the exact retained bytes.

## Making and preserving

At the Making Bench, choose a recipe, name it and optionally give an intent. `#draft-button` creates a private checked artifact. `#preview-button` opens its actual HTML in `#artifact-frame`; `#portal-close` returns to the workshop and `#publish-button` publishes, or use the preview’s publication shortcut. Each accepted published version earns exactly 100 **game XP** and creates or updates a physical building. Drafts, contributions, reports, discoveries and rehearsal runs grant no XP.

Each building offers its actual artifact, a version selector, receipt, attributed contributions, version-bound reports and Founder-only repair. Repair creates the next private draft while the current published version stays open. Publication retains all earlier versions as flat snapshots and records an earned game method for the checked repair. SHA-256 and UTF-8 byte size verify document identity, not the truth of its content. All host-rendered untrusted titles, intents, names and notes use `textContent`.

Recipes:

- **Comic archive:** a working page reader for six unchanged recovered original JPEGs: cover_a, p3, p4, p5, p10, p13. Previous, Next and Enlarge operate on actual artwork. Missing assets are labelled unavailable. `globalThis.NGL_ASSETS.pages` allows the standalone packager to supply embedded image data.
- **Unicode music loom:** each Unicode code point selects one of 24 semitones above 130.81Hz; notes begin 190ms apart. Web Audio starts on Play only. Stop closes the active audio context. Download preserves the score and its exact authored mapping.
- **Source observatory:** adds attributed observations and counterevidence in the open sandbox and downloads their JSON. URLs are references; the artifact does not retrieve or verify them.
- **Custom HTML / portable request:** self-contained inline HTML interactions, or an editable portable AI request with a JSON download. No provider is contacted.

The iframe has `allow-scripts allow-forms allow-downloads`, without `allow-same-origin`. Every recipe starts with a restrictive CSP. The client also imposes a trusted policy before any imported artifact markup, independent of the imported document’s own headers: network connections, subframes, objects, external scripts, base URL changes and form submission are blocked. Images are limited to embedded data and the six exact local recovered comic URLs. This presentation wrapper does not change stored HTML or its receipt. Standalone presentation maps those six known source URLs to the package’s embedded artwork, allowing a source-world save to travel into the offline package without rewriting its evidence. The separately generated exhibition owns its nested-frame policy. Recipe UI states that its local interactions are transient until downloaded. The main service must permit these inline sandbox scripts in its inherited frame policy; browser checks exercise actual buttons and images rather than treating structural recipe checks as execution proof.

## Saves and authority

Private saves use localStorage key `ngl.common-ground.v2`, keeping the preceding save at `.backup`. Loading validates exact artifact bytes and retained history; a valid backup can recover an invalid primary. Quota or storage failures are visible and do not claim a successful save. The Journal exports JSON, validates a selected import (32MiB world limit, 4MiB per generated document), and can recover the previous backup. Raw custom input is bounded to 128KiB UTF-8 for draft and repair. Imports always enter a private world and never authorize shared actions.

Shared mode uses the locked HTTP DTOs and SSE: viewer-specific `world` events and actual `presence` arrays. Open creation notes update from SSE without replacing an unsent contribution or report. Login keys are never saved in localStorage or exports. Failed connectivity leaves the current shared role intact and does not switch to a private Founder. A Founder-to-Witness transition clears private draft references, panels and preview bytes. Import persistence completes before the shared event stream is closed, so a quota failure retains the existing shared session and stream. Shared mutation trust belongs to the server; browser actor objects have no shared authority.

## Focused verification

Run `node --test test/game-model.test.mjs test/game-geometry.test.mjs`. Eight focused tests pass. These started RED with absent implementation, then passed with immutable publication, Witness rejection, private draft filtering, exact receipts, retained repair versions, stale-write rejection, attributed Unicode contributions/reports, discovery deduplication, bounded rewards, tamper rejection and river/bridge/building route assertions. A further RED bank-edge case caught grid rounding into water; the corrected start point stays walkable. Root integration owns the full suite, service and standalone browser acceptance.

Frontend-focused real Chromium evidence used a disposable service and separate contexts at 1440×1000, 390×844 and 320×700. One click produced three actual creations, 300 game XP, a stage with six passing rehearsal checks, no JavaScript page errors and no horizontal overflow. Separate journey checks preserved Unicode text literally, a report against v1, retained v1 after v2 and an earned method. After the inherited HTTP policy was corrected, the actual comic decoded at 700px source width, Next changed its counter to 2/6, Loom Play reported eight running Unicode notes, Stop closed the audio context, and an actual downloaded JSON score retained those Unicode characters. Structural rehearsal checks alone do not prove those interactions executed. See the root browser report for the final integrated recipe and standalone results.

Two independent browser contexts additionally verified shared Witness arrival, authenticated Founder login, private draft omission from the other context’s DTO, publication over SSE, a Witness Unicode contribution appearing in the Founder’s already open notes, preservation of the Founder’s unsent textarea, and logout removing private draft text from both visible and hidden panel DOM. No JavaScript page errors occurred.

A source-generated comic world was exported and imported into the exact generated standalone HTML bytes delivered through a disposable local HTTP server. The imported original decoded at 700px, Next reached 2/6, re-export retained the identical source HTML and SHA-256 receipt, and the launch rehearsal passed 6/6 with zero subsequent HTTP requests and no JavaScript page errors. Direct `file:` opening could not be verified: the managed Chromium `URLBlocklist` blocks all URLs except its configured HTTP/HTTPS/WebSocket and browser UI allowlist. That policy was preserved. The HTTP-delivered byte-identical check establishes package behavior without claiming an executed direct-file journey.
