# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through the repository's [GitHub security advisory page](https://github.com/No-Gas-Labs-Official/no-gas-labs/security/advisories/new). Do not disclose credentials, exploit details, or other sensitive information in a public issue.

## Scope

Reports involving exposed secrets, authentication or authorization bypasses, unsafe input handling, dependency vulnerabilities, and data disclosure are welcome. Please include the affected revision, a concise reproduction, and the potential impact when safe to do so.

## Response

The maintainers will acknowledge a report as soon as practical, assess its impact, and coordinate remediation and disclosure with the reporter.
