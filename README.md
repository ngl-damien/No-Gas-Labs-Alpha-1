The AOTA inspector and T.R.U. workbench are separate useful components. `npm run compounding` compares the exact Meteor exporter against a declared component exporter on frozen Task A/B profiles and runs the extracted deliverables. This tests new component-delivery coverage, not a speedup between unequal outputs. `npm run recover:institution` reads the durable continuity record in a new process. The exporter requires Linux procfs and Node24; validation also requires Python3.9+ standard library, with no pip dependencies.

In shared play, TownSquare and Journal → Projects, evidence and Founder Gate expose installed project records. Set `NGL_INSTITUTION_REPORT` to the retained experiment JSON to install that read-only projection. Reports grant no XP or authority. Founder-only decision APIs reuse the authenticated session, retain exact evaluation bytes and enforce server deadlines, revisions and request idempotency. They record dispositions without promoting code. No operational policy or pending decision is created by default. ## Play and operate Alpha1

The Meteor Commission adds **The Common Ground**, a walkable institution-building world, and **Caveman Launchpad**. The big button makes three real playable creations, checks their bytes and builds a portable exhibition. Ordinary private play needs no account, API key or paid model call. A shared service supports real Witness sessions, contributions, retained versions and authenticated Founder publication.

With Node24 or newer, no dependency installation is needed:

```sh
npm start             # local world and shared service
npm run verify        # tests + portable build + actual institutional exercise
npm run build         # portable game, exhibition and source ZIP in dist/
npm run meteor        # signed local courier, real Forge jobs, strict ledger
```

The build's `play.html` carries the workshop and original comic artwork in one file; `exhibition.html` opens a prepared three-creation public exhibition. Use a modern browser; export your private save before clearing browser storage. Browser policies can restrict local-file execution or storage. The source package also starts with `npm start`. Public phone-accessible hosting remains a separate deployment operation.

The new mechanisms are executable modules, with explicit limits:

- [Strict kernel and durable ledger](docs/meteor/kernel.md): exact scopes, five-stage admission, verified bytes, idempotency and replay.
- [Signed courier](docs/meteor/courier.md): durable requests, enrolled Ed25519 acknowledgment/response envelopes, preserved dissent and explicit failure. The included fixture is a real local process; external model providers require actual enrollment and transport.
- [Bounded Forge](docs/meteor/forge.md): isolated source copies, real candidate execution and repository verification, parent-owned checks, timeout/output bounds and measured reports. It is a trusted local-process runner, with no hostile-code OS sandbox or automatic merge.
- [Playable world](docs/meteor/world.md) and [shared service](docs/meteor/server.md): private saves differ from shared Founder authority. Game XP does not grant institutional authority.
- [Commission contract and baseline](docs/meteor/CONTRACT.md), [mechanism review](docs/meteor/REVIEW.md), [web review](docs/meteor/WEB_REVIEW.md) and [recovery](docs/meteor/RECOVERY.md).

For browser development checks, Python Playwright and Chromium are optional test tools: `python3 scripts/verify-browser.py --standalone`. That check uses disposable state and a fake fixture credential. It never posts publicly or calls an external AI provider.

Runtime state and the generated Founder key live under ignored `.runtime/` by default. The key is never printed or served. Configure `NGL_FOUNDER_KEY` securely for a real shared operator; never paste its value into source or chat. `HOST`, `PORT` and `NGL_DATA_DIR` configure the local service. The service enforces one writer per data directory. See recovery instructions before removing a stale lock.

## Constitutional invariant

> A model's assertion is never sufficient evidence that the state it describes is correct.

Alpha 1 begins with that rule as executable architecture, not branding.

The Lab separates:

`CLAIMED → AUTHORIZED → EXECUTED → OBSERVED → ADJUDICATED`

No actor may promote its own claim directly to `OBSERVED`. Observation requires an evidence reference produced outside the claim itself. Canonical state is derived from accepted events; rejected and failed events remain history.

## Genesis acceptance condition

The repository earns its first capability when an executable reducer:

1. rejects a self-certifying claim;
2. accepts an observation carrying external evidence;
3. preserves both events in history; and
4. produces deterministic canonical state.

Until that executes successfully, the capability is **CLAIMED**, not **OBSERVED**.
