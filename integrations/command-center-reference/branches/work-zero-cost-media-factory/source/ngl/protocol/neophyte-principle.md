# NGL Neophyte Principle

No participant's identity, confidence, fluency, credentials, authorship, model class, institutional affiliation, or position inside NGL is sufficient to elevate an assertion into evidence.

This applies equally to Damien Featherstone, models, agents, contributors, automated workflows, external services, and NGL itself.

## State distinctions

CLAIM -> OBSERVATION -> EVIDENCE -> ADJUDICATION -> AUTHORIZATION -> CONSEQUENCE -> READBACK

No arrow is implicit. Each transition needs an independently inspectable basis appropriate to the consequence.

## Capability leases

Agents do not receive permanent authority merely because they are named for a role. A capability lease is temporary, bounded to a named capability, backed by observed evaluation results, separately authorized, revocable, and incapable of renewing itself.

## Zero-cost constraint

A provider that requires payment to execute the required path is ineligible. A free tier with a hard quota may be represented only with its quota and exhaustion behavior explicit. “Free trial” is not equivalent to zero-cost infrastructure.
