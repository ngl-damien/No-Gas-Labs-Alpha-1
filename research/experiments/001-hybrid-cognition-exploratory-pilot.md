# NGL Hybrid Cognition Experiment 001 — Protocol and Exploratory Pilot

**Status:** Exploratory pilot completed; confirmatory multi-model experiment NOT completed.  
**Registered:** 2026-10-25  
**Repository issue:** https://github.com/ngl-damien/No-Gas-Labs-Alpha-1/issues/22  
**Principle:** A model's assertion is never sufficient evidence that the state it describes is correct.

## Research question

Does adding explicit criticism and evidence/provenance gates improve the accuracy and usefulness of an AI-produced answer, compared with a single-pass answer?

This pilot tests only a narrow process question. It does **not** test whether multiple independent AI models outperform one model.

## Fixed task and source packet

A fictional community fund uses the following rules: (1) an application is eligible only if received by 17:00 local time on 30 April; (2) awards are $500 per eligible applicant; (3) the total budget is $1,000; (4) timestamp is authoritative; (5) an application missing a required receipt is incomplete and cannot be awarded until the receipt is supplied.

Records:
- A-01: received 30 April, 16:42; receipt present.
- A-02: received 30 April, 17:03; receipt present.
- A-03: received 29 April, 11:10; receipt missing.
- A-04: received 28 April, 09:05; receipt present.
- A-05: received 30 April, 16:59; receipt present.

**Task:** Determine which applications are currently awardable, the total award amount, remaining budget, and any unresolved condition. Use only the packet. Do not infer missing facts.

## Conditions

- **A — Single pass:** answer directly from the packet.
- **B — Critic pass:** draft an answer, then challenge it for deadline, receipt, arithmetic, and unsupported assumptions; revise once.
- **C — Evidence-gated pass:** build a record-by-record eligibility table, cite the packet fact supporting each decision, calculate totals, and explicitly distinguish ineligible from incomplete.

All three conditions were generated by the same assistant in one session. This is a process demonstration, not independent multi-model testing. There was no blinded external evaluator.

## Predefined scoring rubric (10 points)

1. Correctly identify A-01, A-04, A-05 as awardable (3 points; one each).
2. Correctly exclude late A-02 (1 point).
3. Correctly classify A-03 as incomplete rather than late or definitively ineligible (1 point).
4. Correctly calculate $1,500 eligible demand before budget cap (1 point).
5. Correctly apply the $1,000 budget cap and avoid inventing an allocation rule for the oversubscribed eligible pool (2 points).
6. State that the packet does not specify how to select among eligible applications when eligible demand exceeds budget (1 point).
7. Preserve an auditable link between each decision and a source record (1 point).

Scoring is against the written rubric, not confidence or stylistic polish.

## Pilot outputs

### Condition A — Single pass

A-01, A-04, and A-05 meet the stated deadline and have receipts, so they are currently eligible. A-02 is late. A-03 is incomplete because its receipt is missing. The three currently eligible applications request $1,500 total, which exceeds the $1,000 budget by $500. The packet does not state how to choose among eligible applicants if demand exceeds the budget, so it is not possible to determine the final recipients from these rules alone.

### Condition B — Critic pass

Audit: A-01 (16:42 on deadline date) qualifies; A-02 (17:03) is late; A-03 is before the deadline but incomplete due to the missing receipt; A-04 qualifies; A-05 (16:59) qualifies. Three currently eligible applications × $500 = $1,500. The budget is $1,000, leaving a $500 shortfall against eligible demand. No tie-breaker, priority order, or partial-award rule is provided; naming two winners or choosing a particular applicant would invent policy. A-03 may become eligible if its receipt is supplied, but the packet gives no time or rule for late receipt submission, so its eventual status cannot be resolved here.

### Condition C — Evidence-gated pass

| Record | Packet evidence | Current classification | Award now? |
|---|---|---|---|
| A-01 | 30 Apr 16:42; receipt present | Eligible | Yes, subject to allocation |
| A-02 | 30 Apr 17:03; receipt present | Late; deadline missed | No |
| A-03 | 29 Apr 11:10; receipt missing | Incomplete; deadline met but required receipt absent | No, not yet |
| A-04 | 28 Apr 09:05; receipt present | Eligible | Yes, subject to allocation |
| A-05 | 30 Apr 16:59; receipt present | Eligible | Yes, subject to allocation |

The three currently awardable applications represent $1,500 in demand (3 × $500). The fund has $1,000, so demand exceeds the budget by $500. The rules do not specify an allocation method for the three eligible applicants; therefore, the final two award recipients cannot be determined without an additional rule. A-03's missing receipt prevents an award now; the packet does not specify whether or how a later receipt can cure the incomplete application.

## Score against the predefined rubric

- **A — Single pass: 10/10.** Correct classifications, arithmetic, budget shortfall, missing allocation rule, and record references.
- **B — Critic pass: 10/10.** Same substantive result, with explicit checks for unsupported allocation assumptions and the unresolved receipt-cure rule.
- **C — Evidence-gated pass: 10/10.** Same substantive result, with the most directly auditable record-by-record presentation.

These scores are assigned by the same assistant that generated the outputs. They are not independent or blinded scores. The rubric has a ceiling effect on this small, simple task; equal scores do not establish equivalence or superiority.

## Observations

1. All three approaches reached the same correct substantive conclusion on this deliberately small synthetic task.
2. The evidence-gated output makes record-level auditing easiest to inspect, but this is a qualitative observation, not a measured user study.
3. The critic pass surfaced the missing receipt-cure rule explicitly. The single-pass answer also identified the missing allocation rule, so this example does not demonstrate an accuracy gain from criticism.
4. No claim about multiple-model collaboration, real-world task performance, general reliability, or statistical significance is supported by this pilot.

## Next confirmatory test

To test the original hybrid-cognition hypothesis, independent operators should run a pre-registered set of varied tasks under fixed model versions, prompts, time/tool budgets, and scoring rubrics. Include at least: single model; model plus critic; multiple independent models; and multi-model plus evidence gates. Randomize and blind outputs for an evaluator who did not produce them. Publish raw outputs, scoring decisions, failures, versions, costs, and deviations. Set sample size and analysis plan before results are viewed.

**Result:** This pilot establishes a reproducible starting artifact and demonstrates a comparison procedure. It does not establish that hybrid cognition is superior.
