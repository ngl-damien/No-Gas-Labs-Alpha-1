# NGL-133 RETRYTAX

Research manifest dated 2026-10-10.

An offline JavaScript prototype examines user-supplied AI API attempt records and model rates. It distinguishes recorded API outcomes from independently declared task delivery, computes bounded token-cost estimates, and creates deterministic receipts.

Internal controls: 44 named Node tests, 260 independent Python scenarios, 28 desktop/mobile browser assertions. Results are from synthetic fixtures. No independent customer usage or external executable release is established.

This file records experiment scope and limitations, not a commercial claim.
