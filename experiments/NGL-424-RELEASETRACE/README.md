# NGL-424 — RELEASETRACE™

**Positioning:** Before you publish, prove what you reviewed—and which exact bytes you reviewed.

An offline-first release evidence gate for AI disclosure workflows. It binds declared assets to SHA-256 values, checks user-supplied scope decisions and review metadata, tests disclosure/marking evidence references for consistency and file presence, and exports a reproducible unsigned receipt plus findings CSV. An independent Python verifier recomputes the result.

## Demonstrated result

Three synthetic assets produce one release block and one unresolved-scope hold. The files are plain-text fixtures, not real media or genuine compliance evidence.

## Evidence boundary

RELEASETRACE is not legal advice, a legal classifier, a C2PA verifier, a watermark detector, or a compliance certificate. It does not semantically validate evidence files. SHA-256 binds bytes, not authorship or truth. Receipts are unsigned and can be regenerated by anyone with the inputs.
